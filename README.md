📌 AI Based Quiz System

An intelligent quiz web app built using HTML, CSS, and JavaScript.
The system dynamically asks questions, checks answers in real-time, and provides instant feedback — simulating an AI-driven quiz experience.

✨ Features

🎯 Auto-generated questions (MCQ format)

⚡ Real-time scoring & feedback

🤖 AI-like question selection logic

⏱ Timer support per question (optional)

📊 Final scoreboard summary

🌙 Simple & clean responsive UI

🔁 Restart Quiz anytime

🛠️ Tech Stack
Component	Technology
Frontend	HTML5
Styling	CSS3
Logic	JavaScript (ES6+)
Data	Local JSON/JS objects
📂 Project Structure
/ai-quiz-system
│── index.html       # UI layout
│── style.css        # Design & theme
│── script.js        # Quiz logic
│── questions.js     # Question bank (optional file)
│── README.md        # Project description
